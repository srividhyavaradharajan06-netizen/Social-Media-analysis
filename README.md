Social Media Engagement Analytics
Overview

This project explores a social media dataset comprising 5,000 posts across 19 features, including user demographics, content metadata, and engagement metrics. The primary objective is to understand what drives user engagement on social media platforms by analyzing likes, comments, shares, impressions, and watch time across different post types, categories, sentiments, and user demographics.

Objectives
Analyze content performance across various post types and categories
Examine user behavior patterns based on age, gender, and verification status
Investigate device usage and its impact on watch time
Study sentiment distribution and its influence on follower count
Compare engagement rates across different countries
Identify correlations between key numerical variables

Data Preprocessing
Handled 150 missing values across 5 columns using:
Median imputation for numerical columns
Mode imputation for categorical columns
Engineered new features to support deeper analysis:
Engagement Score
Hashtag Count
Month

Tools & Technologies
Python — core programming language
Pandas — data manipulation and preprocessing
Matplotlib & Seaborn — data visualization

Key Deliverables
13 visualizations uncovering patterns and trends in the dataset
Actionable insights into content strategy, audience targeting, and platform behavior

Key Insights Explored
Which post types and categories drive the highest engagement
How demographic factors (age, gender, verification) correlate with engagement
The relationship between device type and watch time
How sentiment impacts follower growth
Country-wise variation in engagement rates
Correlation patterns among numerical variables (likes, comments, shares, impressions, etc.)
